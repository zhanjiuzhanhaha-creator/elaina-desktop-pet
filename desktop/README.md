# Windows 桌面版

使用 Windows 10 / 11（x64）自带的 Windows PowerShell 5.1 与 WPF。下载整个仓库并解压，双击本目录的 `启动桌宠.cmd`。请保留完整 `assets` 目录。

首次运行会创建自己的 `config.json`，仓库不含开发者的称呼、目标、亲密度或位置记录。普通互动无需安装模型。

## 操作与功能

- 待机包含呼吸眨眼、歪头摆发、小微笑、俏皮连眨与打瞌睡，五种动作等概率轮换。微笑、睡眠各 5 秒，其余各 3 秒；状态之间约 0.8 秒过渡。
- 光标移到头顶变成大猫爪，摸头时头发连续受压和回弹。点击触发约 5 秒兔耳、呆毛与爱心星芒，动作结束时耳朵保持竖起。
- 按住左键拖动；双击或右键“聊聊天 / 互动…”打开聊天窗口。右键退出桌宠。
- 七个快捷互动：摸摸头、抱抱、夸夸她、逗逗她、猜拳、晚安、再来一次。输入“石头 / 剪刀 / 布”可猜拳；“叫我小星”保存称呼，“我叫什么”回忆称呼。
- 互动增加亲密度，最高 100，频繁操作有 2 秒增长间隔；离开不会扣分。聊天正文只保留到本次程序退出。
- 专注支持目标与 15 / 25 / 45 / 60 分钟，可暂停、继续和提前结束。暂停不计时，完成获得星星与记录。
- 星星可解锁两种地毯、马克杯、绿萝和星星小夜灯；已解锁地毯可免费切换。
- “我们的记忆”可查看称呼、累计专注、星星、装饰和最近目标。正常退出保存位置。
- 安静模式收起气泡与倒计时并关闭提示音。演示模式把分钟按秒计算，方便快速体验；演示也会计入记录，体验后请关闭。

## 可选：免费本地 AI 短聊

模型没有提交到 GitHub。安装一次后可离线聊天：在本目录打开 PowerShell，执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\安装本地聊天.ps1
```

脚本从官方来源下载 llama.cpp b11718 Windows CPU x64 运行时与 Qwen3-0.6B Q8_0 模型，并按 `local-chat/provenance.json` 校验 SHA256。模型约 610 MiB，另需运行时和解压空间；使用 CPU，无需付费 API。网络中断时重新执行即可复用已通过校验的文件。

安装完成后重启桌宠并打开聊天窗口。服务仅监听 `127.0.0.1:18976`；聊天内容不发送到外部聊天服务。小模型适合中文轻松短聊，能力与速度取决于机器。固定互动立即响应，模型生成期间仍可操作桌宠。没有模型时快捷互动、猜拳、称呼记忆仍然可用。

验证已安装资源：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\安装本地聊天.ps1 -VerifyOnly
```

下载遇到地区网络问题时，可到 [Qwen 官方 Hugging Face 仓库](https://huggingface.co/Qwen/Qwen3-0.6B-GGUF) 下载同名文件，放到 `local-chat` 并运行校验。运行时来源、许可证及模型校验值均在该目录。

## 设置登录自启动

先把整个 `desktop` 目录放到准备长期保留的位置。按 `Win+R`，输入 `shell:startup`，在打开的启动文件夹中放入本目录 `启动桌宠.cmd` 的快捷方式。以后登录 Windows 即会启动；移动程序目录后需更新快捷方式。删除此快捷方式即可关闭自启动。

## 开发与自检

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\Elaina.ps1 -SelfTest
```

自检使用临时配置，不覆盖日常记录。正常配置写入会保留上一份 `config.json.bak`。源码继续使用系统 WPF，没有额外界面框架。

桌面版目前没有内置角色语音、语音识别或联网搜索。浏览器版是单独的互动体验，不能漂浮在其他程序之上；两版数据独立保存。
